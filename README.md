# Interactive-Business-Intelligence-Dashboard---Airbnb-Seattle-Market-Analysis

AirBnB Seattle Dashboard
A comprehensive Tableau dashboard for analyzing AirBnB data for the city of Seattle. This dashboard provides insights into listing prices, availability, and various property attributes, helping users understand the rental landscape in Seattle.

🚀 Project Description
This project features an interactive Tableau dashboard that visualizes data from AirBnB listings in Seattle. It's designed for data analysts, travelers, and property owners who want to explore trends and patterns in the Seattle AirBnB market. The dashboard allows for dynamic filtering and exploration of the dataset.

📊 Data Source
The dashboard is powered by an Excel file named Airbnb Seattle.xlsx, which contains two main data tables:

Listings: Detailed information about each AirBnB listing, including property type, room type, number of accommodates, and review scores.

Calendar: Information about the availability and pricing of listings over time.

These two tables are joined on the id from the Listings table and the listing_id from the Calendar table to create a unified dataset for analysis.

✨ Features
Interactive Filters: Filter data by property type, room type, price range, and number of reviews.

Geospatial Analysis: (If applicable, based on dashboard design) Visualize listings on a map of Seattle to understand geographical distribution.

Price and Availability Trends: Analyze how pricing and availability change over time.

Detailed Listing Information: Drill down to see detailed information for individual listings.

🛠️ Technologies Used
Tableau: The primary tool used for creating the data visualizations and the interactive dashboard.

Microsoft Excel: The format of the source data file.
